# DMV SPPU Assignments

## Data Mining and Visualization (DMV)

This repository contains the practical assignments for the **Data Mining and Visualization (DMV)** subject as per the SPPU curriculum. It covers data analysis, data wrangling, visualization, API integration, and stock market analysis using Python.

## Assignments

| Assignment | Problem Statement                                         | Allocated Dataset                | Notebook File                    | Description                                                                                                                                                                            |
| ---------- | --------------------------------------------------------- | -------------------------------- | -------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1          | Analyzing Sales Data from Multiple File Formats           | Books & Stationery – D08         | `DMV1.ipynb`                     | Analyze sales data from multiple file formats using Pandas and visualize important sales insights.                                                                                     |
| 2          | Analyzing Weather Data from OpenWeatherMap API            | Ahmedabad Weather                | `DMV2 - API.ipynb`, `DMV2.ipynb` | Retrieve weather data using the OpenWeatherMap API, process the data, and visualize weather patterns.                                                                                  |
| 3          | Analyzing Customer Churn in a Telecommunications Company  | Young Customer Churn             | `DMV3.ipynb`                     | Analyze customer information to understand churn patterns and identify factors associated with customer retention.                                                                     |
| 4          | Data Wrangling on Real Estate Market                      | Ahmedabad Residential            | `DMV4.ipynb`                     | Perform data cleaning, handle missing values, transform data, and prepare real estate data for analysis.                                                                               |
| 5          | Analyzing Air Quality Index (AQI) Trends in a City        | Ahmedabad AQI                    | `DMV5.ipynb`                     | Analyze air quality data and visualize AQI trends to understand variations in air pollution over time.                                                                                 |
| 6          | Analyzing Sales Performance by Region in a Retail Company | Urban Retail                     | `DMV6.ipynb`                     | Analyze regional sales and profit performance using data visualization techniques to identify business insights.                                                                       |
| 7          | Analysis and Visualization of Stock Market Data           | Netflix (NFLX) Stock Market Data | `DMV7.ipynb`                     | Retrieve and analyze historical Netflix stock data, including opening, closing, highest, and lowest prices, along with trading volume. Visualize stock price trends and daily returns. |

### Dataset Sources

* **Assignments 1–6:** Allocated datasets provided for the respective practical assignments.
* **Assignment 7:** Yahoo Finance, accessed using the `yfinance` Python library.

## Conclusion

These assignments provide practical experience in data analysis, data cleaning, API-based data collection, data wrangling, and visualization. They demonstrate how Python libraries can be used to analyze different datasets and extract meaningful insights for real-world problems.
